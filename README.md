# Sales Analysis Using Supervised Learning

## Project Overview

This project implements supervised machine learning models for sales classification using a Sales Analysis dataset.

## Models Implemented

* Support Vector Machine (SVM)

  * Binary Classification
  * Multiclass Classification
* Random Forest Classifier

## Objective

The objective of this project is to apply supervised learning techniques to classify sales into different categories and compare the prediction performance of SVM and Random Forest models.

## Machine Learning Workflow

1. Load the Sales Analysis dataset
2. Create sales classification categories
3. Split the dataset into training and testing sets
4. Implement Binary SVM
5. Implement Multiclass SVM
6. Implement Random Forest
7. Evaluate model performance
8. Compare model accuracy
9. Analyze Random Forest feature importance

## Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix

## Models

### Support Vector Machine

SVM is implemented for both binary and multiclass classification using an RBF kernel.

### Random Forest

Random Forest is implemented using multiple decision trees to perform multiclass sales classification.

## Results

The notebook contains the accuracy, classification reports, confusion matrices, and model comparison results obtained from the experiments.
